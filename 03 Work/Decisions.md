# Decisions

A decision log beats memory. Record the reasoning, because that's what you'll need when someone reopens it.

## Format

```
### YYYY-MM-DD — <decision>
- **Context:** what forced the choice
- **Decision:**
- **Alternatives rejected:** and why
- **Revisit if:** the condition that would change the answer
```
