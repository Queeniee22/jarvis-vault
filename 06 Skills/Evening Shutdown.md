# Evening Shutdown

## Prompt

Read the Run log at the bottom of this note first, and apply anything learned there.

Close out the day:

1. Read today's daily note in `05 Daily/`. Read the git log of the `jarvis-hud`
   repo for today if there is one, and check which vault notes were edited today.
2. Append a `## Shutdown` section to today's note with:
   - **What actually happened today** -- from evidence, not from what was planned.
     Commits, notes written, decisions made.
   - **What was left open**, and for each, the smallest next action.
   - **One thing worth remembering** -- if the day produced a durable lesson, write
     it to the right note (`Debug Log`, `Working Style`, `Learning Notes`) rather
     than burying it in the daily.
3. Update `03 Work/Open Threads.md` and the `Next` fields in
   `02 Programming/Projects.md` so tomorrow's [[Morning Brief]] reads from something
   current rather than from yesterday's assumptions.

Then say two sentences out loud: what got done, and the one thing to start on
tomorrow.

If today was genuinely unproductive, say that plainly and without a lecture. The
point is an accurate record, not a motivational one.
