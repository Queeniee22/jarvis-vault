# Job Hunt Brief

## Prompt

Read the Run log at the bottom of this note first, and apply anything learned there.

Read `03 Work/Job Hunt.md`, `03 Work/People.md` and `03 Work/Open Threads.md`.

Then give Mackenzie a job-hunt push:

1. **Gone quiet.** Any application where `Last contact` is more than 7 days ago and
   the status is not `rejected` or `offer`. For each, say who to nudge and give him
   one short follow-up line he can actually send -- not a template with blanks in it.
2. **Owed.** Anything where the `Next` column names an action he has not done.
3. **Thin.** If fewer than 3 applications are active, say so plainly and suggest
   where to look next given his stack (TypeScript, Node, Java, PHP, SQL, React in
   progress). Name real categories of company, not "job boards".
4. Update `03 Work/Job Hunt.md` where you can see something is out of date.

Then say the single most useful thing he could do today out loud, in one sentence.

Be honest when the honest answer is that nothing has moved because nothing was sent.
Do not manufacture encouragement. If the table is empty, say the pipeline is empty
and help him start one rather than reporting "no follow-ups needed".
