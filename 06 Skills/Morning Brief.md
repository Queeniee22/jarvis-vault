# Morning Brief

## Prompt

Read the Run log at the bottom of this note first, and apply anything learned there.

Then put together Mackenzie's brief for today:

1. Read today's daily note in `05 Daily/` (create it if missing, named `YYYY-MM-DD.md`
   with the standard frontmatter).
2. Read `03 Work/Open Threads.md` and `02 Programming/Projects.md`. Pull out anything
   whose **Next** action is unstarted, and anything that has not moved in over a week.
3. Check today's calendar events already shown in the HUD's TODAY panel.

Append a `## Morning brief` section to today's daily note containing:
- The single most important thing to do today, and why it beats the alternatives.
- Anything time-bound (a meeting, a deadline) with its time.
- Any thread that looks stalled, named, with the smallest next action.

Keep it under 150 words. Do not restate the calendar verbatim -- he can see it.
Do not pad it to look thorough; if today is genuinely quiet, say so in one line.

Then say a two-sentence spoken summary out loud.
